# 매일의 습관장

습관을 정하고, 매일 체크하며 동기부여를 받고, 쌓인 기록으로 통계를 내는 개인 습관 트래커입니다.
설치나 서버 없이 `index.html` 한 파일로 동작합니다.

## 기능

- **습관 정하기**: 이름, 하려는 이유, 주간 목표(주 1~7회), 색상
- **오늘**: 오늘 달성률, 상황별 응원 문구, 매일 바뀌는 습관 팁, 이번 주 체크(지난 날 기록 가능), 연속 일수와 다음 배지까지 남은 일수
- **통계**: 30일·90일·1년·전체 기간별 달성률, 습관별 성적표, 요일별 달성률, 최근 12주 추이, 26주 히트맵, 연속 기록 배지(3·7·14·21·30·50·66·100·200·365일)
- **데이터**: CSV 내보내기(엑셀·구글 시트 분석용), JSON 백업과 복원

## 사용 방법

- `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.
- GitHub Pages를 켜면 `https://<아이디>.github.io/habit-tracker/` 주소로 열 수 있습니다.
  (Settings → Pages → Branch: `main`, 폴더 `/ (root)`)

## 데이터 저장

기록은 사용하는 브라우저의 localStorage에만 저장됩니다. 다른 기기로 옮기려면 통계 탭의 JSON 백업을 이용하세요.
처음 열면 예시 습관과 기록이 보이며, 상단의 "예시 지우고 시작하기"로 비울 수 있습니다.
